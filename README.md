#ebay
Write a simple application  (command-line scripting or web app, either is fine) that takes a Universal Product Code (UPC),
such 753759077600 (for a Garmin Nuvi), makes a call to findItemsByProduct and displays the Item Title and Price from the
response in a readable format. We are not  looking for a sophisticated UI, but the results should be formatted for readability.
If the app does a simple command-line print, that is fine. The application must be written in one of the following languages:
PHP, Python, Java, or .NET. Please provide source code for review. 

You will find information on the eBay Developer site (http://go.developer.ebay.com/). Refer to the Finding API and in 
particular, the findItemsByProduct call.  The documentation contains all the information to make the call.
